# week4.1

I kept the concentric square structure from my previous class. In this version, pressing the R key generates a new random seed, and noise() changes the rotation angle of each square to create different patterns. I also added random colors and used an if...else statement to switch the colors randomly between red and black.
While drawing the squares, I also wanted to experiment with map(). I used the X and Y positions of the mouse to control a small movement of the whole pattern. As the mouse moves, the squares shift slightly in different directions, creating an effect similar to a 3D phone wallpaper or parallax effect.
